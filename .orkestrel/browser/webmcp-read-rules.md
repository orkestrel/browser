# rules

## summary

The fleet law for a WebMCP conformance suite and adapter is fixed by five scaffold rule files plus two precedents: @orkestrel/mcp already ships a WebMCP "bridge" (`src/browser/ModelContext.ts`, flat at the environment root, not in `transports/`), an IDL-faithful registry double under `tests/fixtures/modelContext.ts`, a `conformance` Vitest project in `npm test` that pairs a foreign-runner exchange with a digest-pinned vendored schema mirror under `tests/mirrors/`, and a `describe.runIf(isWebMCPDocument(document))` native block whose absence path is an ordinary assertion rather than a skip. The scaffold law permits exactly one substitution in a test: a scripted boundary stub that implements the real foreign protocol minimally and never stands in for project-owned behavior; a vendored mirror is fetched bytes exempt from prose rules and refreshed rather than rewritten; `tests/conformance.test.ts` is the fixed home for "where this package drifts from the official tooling it tracks" and stays in `test`; a conditional skip must cite the mechanism, never the platform; wire-body types keep IDL spelling with TSDoc naming the source; foreign values are owned at arrival and validated only where dereferenced, never with an exact-record guard. No rule names "adapter" or "bridge" as an identifier form, no rule sanctions `tests/fixtures/` or `tests/mirrors/` by name, and no rule fixes how a mirror is marked and dated; the two fleet precedents differ (mcp: dated filename + SHA-256 digest constant + `$id` row; html: fetch URL and date in a comment, no digest).

## facts

- The root law bans mocks, behavioral fakes, module replacement, framework spies, and fake clocks for project-owned behavior and names the permitted substitutes: real implementations, recorders, temporary resources, protocol-faithful fixture servers, and inert data stubs. (../scaffold/AGENTS.md:40)
- The test contract restates the ban for 'project-owned or integrated behavior' and names the four sanctioned instruments: recorders for calls/events, temporary resources for stateful boundaries, protocol-faithful fixture servers for deterministic network peers, and the real external service when its behavior is the claim. (../scaffold/.claude/rules/tests.md:27-28)
- The one permitted stand-in is a scripted boundary stub, allowed 'only when it implements the real interface or protocol minimally, to drive the system under test. It never reimplements project-owned behavior and never stands in for the integration being claimed.' (../scaffold/.claude/rules/tests.md:30)
- An injected collaborator with a real minimal implementation is a sanctioned boundary stub, not a mock; a collaborator reached through a hard-coded global is a missing seam, and a genuinely irreducible gap must be recorded where a reader meets it (what is unproven, why, what would change that). (../scaffold/.claude/rules/tests.md:312-315)
- Browser tests use the real browser and do not replace DOM events, storage, observers, viewports, layout, pointer, or drag APIs 'unless the browser genuinely lacks one'; the host clock is never replaced. (../scaffold/.claude/rules/tests.md:288-294)
- A test fixture server binds to 127.0.0.1 on an ephemeral port (`listen(0)`), never `::1` and never a fixed port. (../scaffold/.claude/rules/tests.md:31)
- A test never asserts an implementation against itself; it compares the answer to a declaration, a fixture, or a second mechanism that could disagree, and asserts the membership a discovered set must have rather than a total a partly empty population satisfies. (../scaffold/.claude/rules/tests.md:34-35)
- Every instrument counts as evidence only after it has failed: pair every probe, comparison, or matrix with a negative control drawn from outside the population it covers; promote an instrument that settled a claim into a test, with its control, before accepting the work. (../scaffold/.claude/rules/quality.md:32,40)
- The probe promotion rule: a probe that settles a claim becomes a test in the mirrored location that proves the real source; every other probe is deleted; a probe is never committed, and a type probe lives in the source tree beside what it measures and must be deleted before the unit returns. (../scaffold/.claude/rules/tests.md:108-112,138-142)
